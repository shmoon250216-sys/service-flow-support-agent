# 升级验收 · 2026-09-22

## 已验证

- 55 项 unittest/API 回归通过；临时数据库验证权限、会话历史、字符预算、模拟模型历史输入、人工接管及重启持久化。
- 两个独立 SQLite 连接并发确认同一订单的不同 token，退款账本只有一条。
- 实际抛出 TimeoutError 后第二次执行成功；不是仅检查故障布尔标记。
- 对其他会话、其他客户、非接管客服、过期令牌、错误金额、缺失输出字段进行拒绝测试。
- 同一订单在另一个会话进入人工处理后，原提案也无法继续自动提交。
- 真实浏览器双标签页验证知识问答、上下文追问、等待人工、客服接管回复、客户轮询收到回复、刷新恢复、结案和退款确认；1440px/390px 检查无横向溢出，无浏览器脚本异常。
- 固定评测仍通过；其中故障任务改为每个任务独立订单，避免订单级幂等影响统计。

## 本次复查修正

- 模型不能覆盖明确的安全/退款/人工意图；故障反馈不会被历史中的退款字样带回自动退款。
- 工具输入由不完整 required 列表升级为类型/范围/extra=forbid，输出为具名 Pydantic 模型。
- 退款令牌改为随机、有有效期、绑定会话；本地副作用与订单状态同事务。
- 人工接管阻断自动动作；安全工单禁止恢复自动排障；前端用户内容通过 textContent 渲染。
- 已确认或过期提案不再显示可点击确认按钮；页面显示订单产品、金额与退款状态。

## 尚未验证/尚未实现

未调用真实模型（没有配置外部 API 凭据），相关分支通过替身验证输入结构。未接真实支付、物流、第三方客服；未运行公网部署、压力测试或容灾演练。没有 LangGraph interrupt、MCP、自主工具循环、语义摘要或跨会话长期记忆。

凭据映射不是完整 SSO，演示登录不能公开部署。退款配件齐全/损坏等复杂政策尚未采集，规则只涵盖模拟订单归属、签收天数、状态和金额。不同于实际生产验收，不能据此宣称「已接企业生产」或给出线上 SLA。

遗留待扩展：对长会话原文做归档/TTL；将共享锁改为会话级异步调度；为进程中断请求建立租约恢复；外部支付幂等与对账；生产身份网关、限流、监控与告警。

## 0.3 工单化验收

- 60 条、72 轮固定合成场景回归全部通过，输出带数据 SHA256；不是独立泛化评测。
- API 检查版本必填、结案分类、非法转交目标、客户不能访问工单后台、普通客服不能主管重开/死信重试。
- 工单测试检查等待客户后恢复处理、转交撤销旧负责人修改权限、主管重开重新计时、迟到回复记录超期。
- 发布事件失败时业务变更回滚；消费成功后未确认的重复投递在本地收件箱去重；租约过期后的旧确认无效；独立连接不能同时领取同一事件。
- 真实浏览器验证客户补充、转交、旧客服按钮禁用、结案分类、主管重开、审计和本地通知投递；客户和客服 390px 页面均无横向溢出，无脚本错误。

尚无工作时间日历、跨组织队列隔离、外部通知投递、真实物流/维修单/支付、生产 SSO。SLA 是配置后的规则计时，没有对外服务可用性承诺；通知去重不等于任何外部副作用都能 exactly-once。
