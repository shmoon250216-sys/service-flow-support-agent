# ServiceFlow｜智能售后工单 Agent

Python / FastAPI / Pydantic / SQLite / FSM / RBAC / SLA / Transactional Outbox

**流程编排：**面向排障反复追问与人工交接，设计持久化工单状态机（FSM），支持待接管、处理中、待客户补充、结案及主管重开；通过角色与负责人校验约束操作，人工阶段暂停自动动作。

**上下文治理：**为避免多轮追问丢失主题，保存角色消息并按窗口与字符预算组装历史，用结构化快照交接订单、主题和近期交流；支持主题补全及排障失败转人工，原始记录尚未实现归档。

**服务时限：**为区分普通问题和安全问题，建立技术、账务、安全队列与首次响应/解决 SLA，后台扫描超期并记录通知；转交不重置期限，等待客户继续计时，规则不等于线上可用性承诺。

**请求可靠性：**为防止并发修改覆盖及业务成功后通知丢失，使用版本号条件更新和 Transactional Outbox，将工单状态、审计、事件同事务提交；投递支持租约、指数退避、死信重试及事件 ID 去重。

**动作安全与验证：**为避免未确认退款和重复副作用，以 Pydantic 契约、限时确认与订单唯一账本限制写操作；通过 55 项测试与 60 条/72 轮合成场景回归，覆盖权限、SLA、事务回滚和退款去重，未接真实支付。

代码与测试为 AI 协作开发；以上描述对应仓库功能，不表示已接企业生产或个人已独立掌握全部模块。面试前应能自行复现并解释关键取舍。
