# 简历项目描述：ServiceFlow

Python / FastAPI / Pydantic / SQLite / REST API

- 为消费电子售后实现多轮排障、订单核验、退款确认和人工协作工作台，使用同一会话串联客户问题、知识来源及工单处理记录。
- 持久化角色消息，采用近期消息窗口、字符预算和较早用户摘录构建上下文；追问补充主题，排障失败反馈转入人工，可选模型分类器接收历史背景。
- 设计等待人工、客服接管、恢复自动服务与结案状态，接管时携带订单和历史，按身份限制操作；紧急工单禁止恢复自动排障。
- 为五类工具定义严格输入与输出契约；退款以限时随机令牌明确确认，通过事务和订单唯一约束保证本地账本去重，支持瞬时异常重试与事件记录。
- 32 项测试覆盖上下文、权限、重启、人工协作及并发退款，并完成客户/客服双页面和移动端交互验收。

事实边界：合成订单与本地模拟退款，非真实企业生产接入；自建持久化状态机，没有 LangGraph interrupt 或自主工具循环。真实模型效果尚未验证。
